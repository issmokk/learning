# learning

Personal learning library — curated knowledge collections from engineers worth following.

Live site: https://issmokk.github.io/learning/

## Structure

```
/                   → curator index
/feezan-khattak/    → Feezan Khattak (payments, distributed systems)
```

## Adding a new curator

1. Create `<curator-slug>/index.html` with the content
2. Add a `<a class="curator">` block to the root `index.html`
3. Commit and push — GitHub Pages auto-deploys from `main`
